# NDT Inspection System

Digital Non-Destructive Testing (NDT) Inspection and Evaluation System.

## Overview

NDT Inspection System is a web-based application designed to digitalize
the inspection, mapping, calculation, and evaluation process of NDT indications.

## Technology Stack

### Frontend
- React
- Vite
- TypeScript
- React-Konva
- Redux Toolkit
- TanStack Table
- React-Bootstrap
- Tabler Icons
- jsPDF
- html2canvas

### Backend
- Python
- REST API
